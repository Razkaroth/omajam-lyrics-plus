# Changelog

## 1.0.0 - 2026-08-26

Initial Lyrics+ Edition, based on OmaJam 1.1.1 by Nathan Ollerenshaw.

### Added

- Synchronized embedded `LYRICS` support for local FLAC and M4A files.
- Album-art lyrics stage with active-line highlighting and smooth auto-follow.
- Click-to-seek, hover timestamps, radial line progress, and instrumental cues.
- Responsive lyrics-only layout for narrow panels.
- Two-percent volume adjustment by scrolling the panel's volume bar.
